7 DAYS MAX LEVEL 2000 - v1.0.0

Raises the player level cap from 300 to 2000. Keeps the existing XP curve,
skill points per level, perk limits, and health/stamina progression. The
death XP penalty follows your selected death settings through the new cap.

Target: 7 Days to Die V3.3.0 stable, PC/Steam.
Validation: XML patches checked against V3.2 game configuration files.
V3.3.0 in-game testing has NOT been performed. See the repository README
for a read-only compatibility check and an in-game verification procedure.

INSTALL
1. Exit the game. Back up your save before using this mod.
2. In Steam, right-click 7 Days to Die > Manage > Browse local files.
3. Create a Mods folder there if it does not exist.
4. Copy this entire SevenDaysMaxLevel2000 folder into Mods.
5. Confirm the final path is Mods/SevenDaysMaxLevel2000/ModInfo.xml.
6. Launch the game and try a COPY of your existing save first.

Alternatively, on Windows use %APPDATA%\7DaysToDie\Mods. Install in only
one location. No DLL, Harmony, mod manager, or game-file replacement is used.

For multiplayer the host/server must install the mod. A client installation
cannot change progression on someone else's server. Avoid combining it
with another mod that changes the level cap or replaces the progression tree.

Existing characters are intended to continue from their current level;
this mod does not reset progress or grant levels automatically. It adds
no new perk ranks. Skill points can accumulate after all perks are bought.

Keep this mod installed once you level past 300. To return to vanilla,
restore your pre-mod backup; removing the mod lowers the cap again.
